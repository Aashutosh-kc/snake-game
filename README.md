## Minimum Requirements
- Visual Studio 2022
- CMake 3.28+
- Git 

## How to run 
1. Clone the repo
```bash 
    git clone https://github.com/Aashutosh-kc/snake-game.git
```
2. Open the folder in Visual Studio.
3. Select snake.exe as startup item.
4. Hit the green run button at the top.
